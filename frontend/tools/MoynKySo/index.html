MOYN Ký số — ký hợp đồng bằng USB token ngay trên trang web

Trình duyệt không đọc được USB token, nên để ký số ngay trên trang web cần chạy công cụ nhỏ này trên máy tính Windows có cắm token (giống "công cụ ký" của các nền tảng hợp đồng điện tử khác).

⬇ Tải MoynKySo.exe

  1. Cắm USB token, chắc chắn phần mềm của nhà cung cấp chữ ký số (VNPT-CA, Viettel-CA, FPT-CA, MISA, BKAV…) đã cài — token phải hiện trong kho chứng thư Windows (như khi kê khai thuế).
  2. Mở MoynKySo.exe. Lần đầu Windows SmartScreen có thể hỏi — chọn More info → Run anyway. Chương trình nằm ở khay hệ thống (biểu tượng khiên), không cần làm gì thêm.
  3. Quay lại trang ký hợp đồng, chọn tab Ký bằng chữ ký số → Ký bằng USB token, chọn chứng thư, nhập PIN khi token hỏi.
An toàn: công cụ chỉ lắng nghe http://localhost:8765 trên máy bạn, chỉ trả lời trang web của MOYN, chỉ ký đúng dữ liệu băm của hợp đồng bạn đang mở và luôn hỏi bạn xác nhận trước khi gọi token. Khóa riêng không rời token, không gì được gửi đi ngoài trang web bạn đang ký. Mã nguồn: thư mục tools/MoynKySo của phần mềm.

Không muốn cài gì? Dùng Cách 2 trên trang ký: tải PDF về, ký bằng phần mềm của nhà cung cấp chữ ký số (hoặc Adobe Acrobat Reader), rồi tải lên.

Cần .NET 8 Desktop Runtime (Windows 10/11 thường có sẵn; nếu thiếu, Windows sẽ hướng dẫn tải).
